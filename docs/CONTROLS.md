# Режимы просмотра

Без параметров открывается закреплённый ракурс на луну и цитадель с живой
атмосферой. Кнопка «Смотреть кино» открывает единый плеер.
Свободная камера доступна по `?inspect=upper` и другим режимам ниже.

| URL | Вид |
| --- | --- |
| `?inspect=street` | Улица |
| `?inspect=quarter` | Квартал |
| `?inspect=city` | Весь город |
| `?inspect=citadel` | Цитадель |
| `?inspect=upper` | Нижний ракурс на цитадель и луну |
| `?film=tour` | Непрерывное кино, 36 секунд |
| `?film=tour&frame=3&paused` | Закладка начала роста Гетсуги |
| `?film=tour&frame=7&paused` | Парящий город целиком |
| `?film` | Исторический cinematic, 26 секунд |

Мышь: левая кнопка — вращение, правая — сдвиг, колесо — приближение.
W/A/S/D перемещают камеру и точку вращения по горизонтали; Q/E — по высоте.
Shift ускоряет перемещение. Кнопки высоты работают при коротком нажатии и
удержании. Клавиши 1–5 выбирают пресеты из таблицы.

## Луна и облака

В GETSUGA доступны четыре фазы события и шкала времени.
Пауза облаков независима от выбранной фазы. Переключатели позволяют убрать
небо целиком либо отключить луну и материю, оставив погоду.

Панель камеры содержит три объектива и настройку угла обзора, дистанции,
высоты относительно вершины, азимута и положения луны в кадре.
Параметры этих ползунков сохраняются в URL. Произвольное перемещение WASD
или мышью не сериализуется как полноценная закладка позиции.

| Параметр | Назначение |
| --- | --- |
| `ut=21.8` | Фаза события в секундах |
| `sky-motion=0` | Остановить движение облаков |
| `mt=21.8` | Зафиксировать время движения для сравнения кадров |
| `ufov=80` | Угол обзора верхней камеры |
| `udist=415` | Дистанция верхней камеры |
| `uheight=-246` | Высота относительно вершины |
| `uazimuth=16` | Азимут вокруг цитадели |
| `uframe=0.28` | Нормированное положение луны в кадре |
| `sky=0` | Отключить верхнее небо |
| `matter=0` | Отключить луну и материю |
| `debug=1` | Включить доступ к объектам сцены из консоли |

Пример воспроизводимого ракурса:
`?inspect=upper&sky-motion=0&ut=21.8&mt=21.8`.

## Единый плеер и закладки

`?film=tour` — основной непрерывный маршрут: ночной город, улица, поворот
к цитадели, появление света и облаков, обход здания, белый ракурс, Гетсуга
и раскрытие парящего острова. Длительность 36 секунд; исчезновение Гетсуги
пока не входит в историю.

Закладка останавливает всю сцену. Play / P продолжает кино с выбранной
секунды; отдельного переключателя режима и независимого движения нет.
В последнем кадре камера остаётся на месте, а Play продолжает движение
облаков и материи. Финал больше не перезапускает кино; для повтора выбери1.
Стрелки ←/→ выбирают предыдущий/следующий кадр с быстрым направленным
перелётом и цветовым смазом. Семь остановок сохраняют прежние метки URL: 0, 7, 16.5, 22,
38, 54 и 66. Метка 54 — прежний главный ракурс цитадели
и полной луны справа; в новом Cinema он приходится на 29-ю секунду. Последний кадр раскрывает остров целиком.

«Гетсуга» и «Кромка луны» остаются проходами кино. В кадре «Вдоль стен»
камера отодвинута на 16%. Переход связывает выбранные композиции короткой
плавной траекторией с обходом геометрии. Повторный клик меняет маршрут
из текущего положения камеры.
В «Над бурей» камера опущена: луна подходит к верхней границе изображения,
а под ней открывается город. На узком экране наклон сохраняет эту композицию.

Действия сгруппированы по центру над дугой кадров; у каждой кнопки видна
соответствующая клавиша. Переходы ускорены вдвое без смены маршрутов.

| Клавиша | Действие |
| --- | --- |
| 1–7, включая цифровой блок | Выбрать кадр |
| ← / → | Предыдущий / следующий кадр, также из кино |
| P | Пуск с выбранного места / общая пауза |
| H | Скрыть / вернуть управление |

Буквенные клавиши работают по физическому положению и на русской раскладке.
Скрытая панель не отключает горячие клавиши. В текстовых полях они не
перехватываются; стрелки на шкале времени сохраняют обычную перемотку.
Пробел вне кнопок/полей по-прежнему управляет кино; на кнопке пробел/Enter
активируют её. Звуковых контролов в текущем интерфейсе нет.

| Параметр | Назначение |
| --- | --- |
| `frame=1` … `frame=7` вместе с `film=tour` | Открыть закладку на паузе |
| `t=66&paused` | Открыть конкретный момент |
| `hud=0` | Начать со скрытой панелью |

Старые ссылки `view=frames&t=...` поддерживаются как закладки; старый
параметр `motion` не создаёт отдельного такта воспроизведения.

При системном предпочтении уменьшенного движения сцена изначально
остановлена, переходы без ускоренного пролёта. Возвращение в фоновую вкладку
не прокручивает пропущенное время одним скачком.

`?film` без `=tour` сохраняет раннюю 26-секундную последовательность.
Основной маршрут использует актуальную архитектуру и обработку AO-сцены.
