# Публикация

Демо: https://bleach-webgpu.vercel.app/

Репозиторий: https://github.com/vixkosla/bleach-webgpu

Проект собирается в статические HTML, CSS и JavaScript в `dist/`.
Бэкенд, переменные окружения и платные API для работы сцены не нужны.

## Vercel

В репозитории есть `vercel.json` с настройками:

| Настройка | Значение |
| --- | --- |
| Framework | Vite |
| Node.js | 22.x |
| Install | `pnpm install --frozen-lockfile` |
| Build | `pnpm check && pnpm build` |
| Output | `dist` |

Для собственного развёртывания импортируйте репозиторий в Vercel либо
выполните из корня после установки зависимостей:

```bash
vercel link
vercel --prod
```

[Документация Vercel CLI](https://vercel.com/docs/cli/deploying-from-cli).
Для этого проекта подключена Git-интеграция: коммиты в `main` запускают
проверки и публикацию на Vercel.
[Подключение репозитория](https://vercel.com/docs/cli/git).

## Другой статический хостинг

```bash
pnpm install --frozen-lockfile
pnpm build
```

Загрузите содержимое `dist/` и включите HTTPS. Все режимы передаются query
параметрами, поэтому отдельные серверные маршруты для инспектора не нужны.
Если сайт размещается в подпапке, задайте соответствующий `base` в
`vite.config.ts`. Архивный модуль `city.ts` содержит абсолютный путь текстуры;
при его повторном подключении также учитывайте базовый путь.

## Перед обновлением

1. Запустите `pnpm check` и `pnpm build`.
2. Просмотрите актуальный режим в браузере с WebGPU: город, цитадель, луну,
   движение облаков, вращение мышью и подъём Q/E.
3. После публикации откройте публичный HTTPS-адрес без авторизации.
4. Проверьте загрузку HTML/JS/CSS, отсутствие ошибок консоли и реальный кадр.

Vercel запускает `pnpm check` перед каждой сборкой: ошибка типов или геометрии
останавливает публикацию. GitHub Actions содержит такой же workflow для ручного
запуска. GPU-кадр требует отдельного браузерного просмотра: обычная облачная
сборка не подтверждает работу WebGPU.
